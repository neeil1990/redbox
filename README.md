**Titlo** — многопользовательская SaaS-платформа для SEO-специалистов: мониторинг позиций сайта в поисковых системах, анализ релевантности страниц, кластеризация семантики, контроль мета-тегов и ещё более десятка инструментов в едином личном кабинете с тарифами, биллингом и разграничением прав доступа.

## Автор и вклад

Проект основан и спроектирован мной ([neeil1990](https://github.com/neeil1990)) в июле 2021 года; разработка велась командой из двух разработчиков. Мой вклад — **около 2000 коммитов за 2021–2025 годы**, более **230 созданных классов** и **38 моделей**: архитектура ядра платформы, биллинг и флагманский модуль мониторинга позиций. Я также сопровождал production-сервер (деплой, обслуживание БД).

### Ядро платформы

- Каркас приложения и первоначальная архитектура (initial commit — июль 2021).
- Полный цикл аутентификации: регистрация с валидацией, email-верификация по коду подтверждения, восстановление пароля.
- Система пользователей и ролей (Super Admin / admin / пользователи), страница управления доступами с выдачей индивидуальных прав, кастомные middleware (проверка ролей, локаль пользователя, автоудаление неверифицированных аккаунтов).
- Админ-статистика: посещаемость, история действий пользователей и проектов, выгрузки по фильтрам.
- Мультиязычность RU/EN — файлы переводов и переключение локали.

### Тарифы и биллинг

- Архитектура тарифной системы: `app/Classes/Tariffs` — фасад тарифов, интерфейсы периодов и настроек, бесплатный тариф, лимиты по каждому модулю платформы. Новые тарифные опции добавляются без изменения кода инструментов.
- Баланс пользователей, пополнение через платёжный шлюз **Robokassa** (`app/Classes/Pay`), обработка результатов оплаты, автосписание при продлении тарифа.
- CRUD тарифных планов и их значений для администраторов.

### Мониторинг позиций — флагманский модуль платформы

Разработан мной полностью, от схемы данных до интерфейса (15+ контроллеров, ~2 500 строк доменных классов, ~10 000 строк представлений):

- Съём позиций **Яндекс и Google** через сервис XMLRiver: движки поисковых систем по паттерну Strategy (`app/Classes/Position/Engine`), справочник регионов обеих поисковых систем.
- Фоновая обработка через **очереди Redis**: постановка съёма в очередь, автообновление позиций по расписанию (`AutoUpdatePositionQueue`), подсчёт вхождений (`OccurrenceQueue`), копирование проектов с ключевыми словами.
- Аналитика: графики динамики позиций, виджеты статистики через фабрику (`Widgets/WidgetsFactory` — ТОП-10/30/100, освоенный бюджет, количество проектов), расчёт процента освоения бюджета.
- Экспорт отчётов в **Excel / CSV / HTML / PDF** через фабрику форматов (`app/Exports/Monitoring/Format`), настраиваемые колонки отчёта.
- Группировка запросов, цены за ключевые слова, права доступа к проектам между пользователями, панель инструментов проекта (паттерн Factory для кнопок модулей).

### Другие модули

- **Мониторинг мета-тегов** — контроль изменений title/description/h1 на страницах, история проверок, сравнение версий, экспорты в Excel, автопроверки по расписанию (cron-классы).
- **Поведенческие факторы** — модуль проверки и верификации поведения на сайте с публичным API.
- **Консольные команды и планировщик** — оптимизация БД, обновление гео-справочника Google, обслуживание поисковых индексов; расписание задач в `Console/Kernel`.
- Vue-компоненты интерфейса, страницы профиля, конкуренты, публичные страницы.

В коде применяю паттерны **Factory, Facade, Strategy** (движки поисковых систем, форматы экспорта, виджеты), выношу бизнес-логику из контроллеров в доменные классы, тяжёлые операции — в очереди.

## Возможности

### SEO-инструменты

- **Мониторинг позиций** — отслеживание позиций сайта по ключевым запросам в Яндекс и Google с привязкой к регионам, группировкой запросов, графиками динамики, сравнением с конкурентами и экспортом отчётов в Excel.
- **Анализ релевантности** — сравнение страницы с ТОПом выдачи: анализ текста и ключевых слов конкурентов, история проверок, теги проектов, публичный шаринг результатов.
- **Кластеризация семантики** — автоматическая группировка ключевых запросов по выдаче (hard/soft-кластеризация) с обработкой больших ядер через очереди.
- **Мониторинг мета-тегов** — контроль изменений title, description, h1 и других тегов на страницах проекта, сравнение версий и уведомления об изменениях.
- **Текстовый анализатор** — анализ тошноты, водности и вхождений ключевых слов с учётом морфологии русского языка (phpMorphy).
- **AI-генерация контента** — генерация текстов по макросам со стоп-словами и историей генераций.
- **Мониторинг доменов** — контроль доступности, HTTP-заголовков, SSL и WHOIS-данных (сроки регистрации, смена владельца).
- **Анализ конкурентов** — поиск и сравнение конкурентов по поисковой выдаче.
- **Вспомогательные утилиты** — проверка уникальности текста, сравнение списков, подсчёт длины текста, генератор паролей, SEO-чек-листы с задачами и уведомлениями.

### Платформа

- **Тарифы и биллинг** — гибкая система тарифов с лимитами по каждому модулю, пополнение баланса через платёжный шлюз, автоматическое списание.
- **Роли и права доступа** — разграничение прав на базе spatie/laravel-permission (Super Admin, admin, пользователи), выдача индивидуальных прав.
- **Realtime-уведомления** — собственный WebSocket-сервер (beyondcode/laravel-websockets, протокол Pusher) + Laravel Echo на клиенте.
- **Telegram-бот** — уведомления о событиях в проектах.
- **Админ-панель** — управление пользователями, статистика посещений и использования модулей, история действий.
- **Партнёрская программа**, email-верификация с кодами подтверждения, мультиязычность (RU/EN).

### Архитектурные решения

- Тяжёлые операции (съём позиций, парсинг выдачи, кластеризация, анализ релевантности) вынесены в **фоновые задания** (`app/Jobs`) и обрабатываются воркерами очередей — интерфейс остаётся отзывчивым, прогресс отображается в реальном времени через WebSockets.
- Бизнес-логика инкапсулирована в сервисных классах (`app/Classes`) — контроллеры остаются тонкими.
- Регулярные операции (обновление позиций по расписанию, оптимизация БД, обновление гео-справочников) выполняются через **планировщик Laravel** и консольные команды.
- Лимиты тарифов проверяются централизованно на уровне модулей — новые тарифные опции добавляются без изменения кода инструментов.

## Установка

Требования: PHP ≥ 7.4 (расширения `gd`, `json`), Composer, MySQL, Redis, Node.js.

```bash
# 1. Клонировать репозиторий и установить зависимости
git clone https://github.com/neeil1990/titlo.git
cd titlo
composer install
npm install

# 2. Настроить окружение
cp .env.example .env
php artisan key:generate
# указать в .env доступы к БД, Redis, почте и ключи внешних API

# 3. Миграции
php artisan migrate --seed

# 4. Сборка фронтенда
npm run dev        # или npm run prod для production

# 5. Запуск
php artisan serve              # приложение
php artisan queue:work         # воркер очередей
php artisan websockets:serve   # WebSocket-сервер
```
